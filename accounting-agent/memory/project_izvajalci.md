Večina izvajalcev so slovenski s.p. in d.o.o.; manjšina tuji (EU/tretje države).
**Why:** uporabnik je potrdil ob postavitvi (7. 11. 2026); določa privzeto obravnavo.
**How to apply:** domači izvajalec = privzeta pot (4100/4101, domači DDV, konto 220). Tuj = vedno ZASTAVICA
za reverse charge (4102/221). Fizične osebe so redke: ZASTAVICA.
